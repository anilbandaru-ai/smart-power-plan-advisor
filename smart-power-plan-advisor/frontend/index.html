How these estimates work

PDF mode uses a custom formula: Energy = usage times mapped EFL average, plus PDF base/usage fees and delivery, minus eligible credits. This repeats effects already embedded in the average and is not an actual tariff bill. Renewal assumptions apply to these custom charges. A supported ZIP does not guarantee available PDF plans. Demo mode uses fictional rates. Bill estimates exclude taxes and switching fees; entered switching costs are reflected separately in net savings. Usage scenarios are sensitivity checks, not forecasts.
